# Render Keep-Awake

This is a Vite static frontend repo. Static-only Render sites do not run an Express or Next API server, so the safe keep-awake target is the public site root.

## Endpoint

```txt
GET /
HEAD /
```

## Render usage

Use the deployed Render URL:

```txt
https://YOUR-RENDER-SERVICE.onrender.com/
```

Ping interval recommendation: every 10-14 minutes.
